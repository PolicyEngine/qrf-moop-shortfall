# qrf-moop-shortfall

PolicyEngine's MOOP imputation experiment fits microimpute's quantile regression forest (QRF) to the 2026 CPS ASEC, and its draws of medical out-of-pocket spending (MOOP) total 3.6% less than the reported values. We measure each cause's share of that shortfall and run microcosm-fit's `RegimeGatedQRF`, which Microcosm uses to build PolicyEngine's microdata, through the same tests. PolicyEngine archived microimpute on November 8, 2026, without changing the QRF code we analyze. Read [REPORT.md](REPORT.md) for the results, the code behind each mechanism and the validation.

- Of the draws' 3.48% expected shortfall, microimpute's quantile grid accounts for 1.76 points and quantile-forest's linear quantile for 1.54, when we average the two orders of removing them. The forest's own mean accounts for 0.18 points in these runs, but its spread across folds can't rule out a forest bias of two points either way.
- One stored sample per leaf doesn't cause the CPS shortfall, and setting `max_samples_leaf=None` lowers the total a further 1.65 points, because quantile-forest then pools leaf samples by count. microimpute's own weighting (`weight_col`, which reaches the split criterion) lowers the total by 0.25 points. Resampling donors by weight, as Microcosm does, raises it by 0.52 points (fold SE 0.54), about 15% of the expected shortfall in these runs.
- [PR 219](https://github.com/PolicyEngine/microimpute/pull/219)'s own code removes the shortfall (expected totals +0.3% unweighted, +0.5% weighted). Microcosm's `RegimeGatedQRF` falls 1.2% short in expectation. The linear quantile of each row's pool costs 0.45 points of that, and interpolating between 203 quantile knots gives back 0.02.
- On a synthetic process with a known conditional mean, the fully grown trees of microimpute's forest and Microcosm's amount forest run 8 to 11% high, because their adaptive splits favor donors with large positive noise. Filling the same trees with donors the splits never saw removes the excess. On CPS MOOP the adaptive fill's total doesn't exceed the honest fill's, though that total contrast doesn't isolate selection.

## Reproduce

Run `scripts/setup.sh` to build the environment, which pins Python, the runtime dependencies and microimpute's commits but not uv or the build tools. Then run the commands in [REPORT.md](REPORT.md#reproduce) to regenerate every file in `results/`. The scripts download Census's public-use CPS ASEC 2026 file themselves, and `results/cps_inputs.npz`, which holds record-level survey data, stays out of git.
